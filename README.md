# 아부라야 · 油屋

팔백만 신들이 쉬어가는 온천장 컨셉의 원페이지 웹사이트입니다. 손님은 사람이 아닌 신들이며, 사람이 나온 사진은 쓰지 않습니다.
레이아웃과 컬러는 아임웹 "호텔월광" 템플릿을 기준으로 했습니다 — 흰 배경, 연회색 푸터, 핑크 포인트(`#f0466e`).

## 구성
| 섹션 | 내용 |
|---|---|
| HERO | 대표 사진 **10장 전체 화면 슬라이드** (메인 이미지 2장 → 신들의 탕 7장 → 공물 모음), 좌우 화살표·점·스와이프, 김 오르는 효과 |
| 01_ ABOUT | 소개 문구 + 사진 3장 |
| 배너 | 콜라보 문구 + 공물 진열대 |
| 4가지 특징 | [神湯] 약탕 · [神饌] 공물 · [お面] 신의 가면 · [御守] 부적 |
| 02_ BATH | 사계절 탕 [春][夏][秋][冬] |
| 03_ SOUVENIR | 신들의 공물과 기념품 (약탕 나무패 · 신찬 만주 · 별사탕 · 가면 · 부적) |
| BATH & HOTEL (예약 페이지) | 객실 3 · 온천 8 카드 (전체 / 객실 / 공용 / 개인 탭) → 선택하면 **상세 패널**(왼쪽 사진 · 오른쪽 설명 · 예약하기) → 예약하기를 누르면 **예약 탭(`#booking`)으로 전환**(호텔 객실 예약 / 온천 단독 예약, 달력 · 인원 · 옵션 · 예약자 정보 · 결제금액) |
| 05_ LOCATION | 어두운 배경 오시는 길 |
| FOOTER | 템플릿과 같은 3단(로고 · 사업자 정보 · 운영 시간) + 예약 버튼, 플로팅 버튼(예약하기 · WhatsApp 상담 · 맨 위로) |

## 폴더 구조
```
index.html
css/style.css
js/main.js
assets/images/
├── hero/main-1.jpg              메인 이미지 1 (첫 번째 슬라이드)
├── hero/main-2.jpg              메인 이미지 2 (두 번째 슬라이드)
├── hero/exterior-bridge.jpg     목욕탕 외관 (붉은 다리)
├── hero/interior-dragon.jpg     목욕탕 내부 (용머리 탕)
├── hero/souvenir-shop.jpg       기념품 진열대
├── interior-mural.jpg           타일 벽화 내탕
├── souvenir/                    기념품 갤러리 5장
└── baths/                       사계절 탕 · 탕 선택 옵션 사진 7장
```
내 사진을 추가·교체하려면 `assets/images/`에 파일을 넣고 HTML의 `data-img`에 `assets/images/파일명.jpg`를 적으면 됩니다.

## 사진
모든 사진은 리포지토리 안(`assets/images/`)에 있어서 인터넷 연결 없이도 보입니다. 외부 사진 사이트는 쓰지 않습니다.
`data-img="사진A.jpg|사진B.jpg"`처럼 적으면 A가 열리지 않을 때 B를 씁니다. 사진이 없는 탕 옵션은 목록에서 자동으로 빠집니다.

## 객실 · 온천 데이터
객실·온천의 이름, 설명, 가격(¥), 인원은 `js/main.js`의 `ITEMS` 목록에서 바꿀 수 있습니다.
**객실 3종 사진**은 온천장 분위기로 생성한 초현실 실사풍 이미지(Higgsfield)를 인터넷 주소로 불러옵니다. 열리지 않으면 Wikimedia Commons 실사 객실 사진, 그것도 안 되면 「客」 화면이 나옵니다.

## 이미지 스타일 통일
온천·객실·상품·배너·소개 사진은 모두 **초현실 실사풍 생성 이미지(Higgsfield)**로 통일했습니다 — 붉은 옻칠, 종이 등불, 김이 오르는 해 질 녘·밤 분위기, 사람·캐릭터 없음.
`js/main.js`의 `GENERATED` 목록이 "로컬 사진 경로 → 생성 이미지 주소"를 연결하며, 생성 이미지가 열리지 않으면 원래 로컬 사진이 나옵니다.
메인 슬라이드 첫 두 장(`main-1.jpg`, `bathhouse-exterior-only.png`)은 지정하신 원본을 그대로 씁니다.

## 히어로 슬라이드
별도 동영상 파일 없이 **HTML·CSS·JavaScript만으로** 재생됩니다.
사진 10장이 옆으로 밀려 넘어가는 CSS 애니메이션(천천히 확대 포함)으로 이어지고,
JavaScript `<canvas>`로 온천 김이 피어오르는 효과를 그립니다.

## 실행
설치나 빌드 없이 `index.html`을 브라우저(Chrome, Edge 등)로 열면 바로 실행됩니다.

```
index.html      ← 페이지 구조 (HTML)
css/style.css   ← 디자인·색상·애니메이션 (CSS)
js/main.js      ← 영상 시퀀스·김 효과·메뉴·아코디언 (JavaScript)
```
