# AI JACUZZI · 湯の宿

일본 전통 목조 온천장(목욕탕) 컨셉의 원페이지 웹사이트입니다.
레이아웃과 컬러는 아임웹 "호텔월광" 템플릿을 기준으로 했습니다 — 흰 배경, 연회색 푸터, 핑크 포인트(`#f0466e`).

## 구성
| 섹션 | 내용 |
|---|---|
| HERO | 목욕탕 **외관 → 내부** 영상 (김 오르는 효과 포함) |
| 01_ ABOUT | 소개 문구 + 사진 3장 |
| 배너 | 콜라보 문구 + 온천 거리 야경 |
| 4가지 특징 | [湯] [食べ物] [お土産] [散歩] |
| 02_ BATH | 사계절 탕 [春][夏][秋][冬] |
| 03_ RESERVATION | 이용 안내 아코디언 + AGREE 버튼 |
| 04_ LOCATION | 어두운 배경 오시는 길 |
| FOOTER | 사업자 정보, 사진 출처 |

## 사진
모든 사진은 Wikimedia Commons의 실제 사진입니다(도고온천 본관, 긴잔온천, 센토 내부, 기노사키 고쇼노유, 쿠사츠 유바타케 등).
HTML의 `data-img="파일명"`에 Commons 파일명을 적으면 `js/main.js`가 해당 사진을 불러오고, 푸터의 PHOTO CREDITS에 출처 링크를 자동으로 표시합니다.
사진을 바꾸려면 `data-img` 값만 다른 Commons 파일명으로 바꾸면 됩니다.

## 히어로 영상
- `assets/hero.mp4`가 있으면 그 영상을 자동 재생합니다.
- 없으면 외관 2컷 → 내부 3컷을 줌·크로스페이드로 이어 보여주는 시네마틱 시퀀스가 재생됩니다.
- `bash tools/make-hero-video.sh`를 실행하면 같은 실사 사진으로 `assets/hero.mp4`를 만들어 줍니다 (ffmpeg, curl 필요).

## 실행
정적 사이트라 `index.html`을 브라우저로 열면 됩니다.
